# Reporting a vulnerability

No public security email has been chosen.

Report a vulnerability to Michael Stokes in person or through a channel he has already given you. Do not open a public GitHub issue for an unfixed vulnerability.

Include what you observed, the version or commit, and whether any shipment or personal data was exposed. Do not include secrets, signing keys, or real documents in the report.

The project has no bug-bounty program and no production service.
