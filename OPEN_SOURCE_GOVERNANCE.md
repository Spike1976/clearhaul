# Open-source governance

Date: 2026-09-30

AGPL version 3 is the approved working license for the ClearHaul server and core. Michael Stokes decided that on 2026-09-30 in CH-D-0014. The LICENSE file is that license text.

The working license is still provisional. A final legal and open-source review has not been done. Integration libraries may use Apache 2.0 later only if that choice is separately approved.

Michael also directed the tree onto the public repository https://github.com/Spike1976/clearhaul. See CH-D-0021. That direction publishes the current foundation. It does not close the final license review.

Material that would be public, if publication is later approved, must not contain secrets, personal information, real shipments, banking data, private investigations, active fraud thresholds, unpatched vulnerability details, or incompatible third-party material. That limit is from the engineering operating order. It is not approval to publish.

These documents do not make ClearHaul ready to publish.
